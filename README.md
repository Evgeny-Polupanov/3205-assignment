# URL Checker
Приложение для проверки доступности ссылок.
# Запуск
## Docker
Для запуска приложения в Docker убедитесь что приложение Docker запущено в системе, запустите в корневой директории репозитория терминал и введите команду
```docker compose up -d```. Затем перейдите по адресу ```localhost:5173``` в браузере.
## Локально
Для запуска приложения локально нужно в каждой из директорий ```backend``` и ```frontend``` запустить команду ```npm install``` и после этого в директории ```backend``` запустить команду ```npm start```, а в ```frontend``` - ```npm run dev``` и перейти по адресу ```localhost:5173``` в браузере.
